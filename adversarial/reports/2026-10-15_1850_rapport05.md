(dépôt de travail, branche `oral`, modification non commitée). Le clone de `repos/` n'est pas touché.

| instance | MOI sans recherche locale | AUTRE_1 | AUTRE_2 | AUTRE_3 | résultat |

| repli (R2, m = 8, 2 Ko) | 507 | 507 | 507 | 507 | solveur 1 073 741 822 964 → ×2,12·10⁹ |

repli (`best/variantes/r2_m1_k63_sans_recherche_locale.in`, 1 963 o, même ratio). On garde m = 8, qui
piège MOI avec ou sans recherche locale.

## Attention : branche locale ≠ version GitHub
Le dépôt de travail est sur `oral` (1a4723b), en retard sur `main` (65d28bf, version clonée et testée).
`main.py` est identique dans les deux (hors cette ligne), mais `utils.py` et `algos/knapsack_slay.py`
diffèrent : la version locale ne fusionne pas les requêtes en double et a LIMIT = 10 000.
Pour tester la modification, le harness accepte `MOI_MAIN=<chemin d'un main.py>` : il prend ce
`main.py` et le reste du code dans le clone de `main`.

```bash
MOI_MAIN=S:/dev/AdvancedProblemSolving/main.py python harness/run_all.py best/instance_repli.in
```
