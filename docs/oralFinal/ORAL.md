# Oral Final

## Consignes

Each group must present its solution to the problem. The oral of 27 minutes (in English or French) will be organized in five parts as follows:

* Algorithmic (6 min): it must include an example of the algorithm execution without any reference to the code.
* Experimental Evaluation (6 min): it must include the experimental protocol (settings, limits, metrics, etc), the experimental analysis with data visualization, and a SWOT analysis.
* Code (3 min): it describes the implementation choices of your final submission.
* Conclusion (2 min).
* Questions (10 min): you can use a whiteboard for answering.
